Operation

The pfcview.jar file actually contains two applications.  The primary one is PFC Viewer, which is a Java Swing GUI application with windows and menus and stuff.  The other one is a simple console application named MailToMbox.  When running these applications, note that all Java commands are case-sensitive.

PfcViewer

To start the PFC Viewer application in Windows, select Run from the Start menu, browse to the pfcview.jar file, and press OK.  If you saved the file to the Windows Desktop, you can simply double-click the file.

Alternatively, you can open a Command Prompt (or MS-DOS Prompt) window, navigate to the directory where you saved the pfcview.jar file, and run the following command:

java -jar pfcview.jar

For versions 0.2 and earlier, use the following command:

java -cp pfcview.jar PfcViewer

The main application window is shown on the right.  To open your Filing Cabinet, select File Open from the menu and use the dialog box to locate your cabinet file.  (This is usually stored in the "organize" sub-folder where the AOL software is installed.  The file is named after your screen name, without an extension, like "JohnDoe123".)  It is strongly recommended that you copy the file from its original location to another separate directory, and work with the copy.

Once the cabinet file is loaded, you will see its folder structure in the left-side window.  Select any folder, and its contents will be listed in the upper right-side window.  Select any mail message in the table, and its text will be displayed in the lower right-side window.

There are a few options that affect the text display; these can be accessed using the Tools Options dialog box.

  • Append mail headers in Text view: When checked, mail headers are appended to the end of the mail body in the display window.  This setting is ignored for HTML mail in the Browser view.

    •  
  • Use Browser view for HTML mail: When checked, HTML mail is displayed in browser mode, which interprets all tags and formats the content.  This feature is still a little flaky so some messages may not display properly.  Text mail is displayed in plain text.

Exporting items to a text file is a matter of selecting a folder, and choosing one of the export options from the menu.  You may select any folder, including the root folder identified by the AOL screen name at the top.  The current export options are listed below.

  • Tools Export Favorites to Html: Exports favorites in the selected folder, and its sub-folders, to an HTML file.  This is a simple way of exporting the favorite URLs into a format that can be referenced by any web browser.  The folder structure is reflected in the file.

    •  
  • Tools Export Mail to Mbox: Exports emails in the selected folder, and its sub-folders, to an mbox file.  This is a standard Unix mail file format, which is also used by many Windows mail clients like Eudora, Mozilla, and Netscape.  The mbox file is a text file, so it can also be opened in any plain text editor.  The folder structure is not preserved in the file.

    •  
  • Tools Export Mail to Mbox+Toc: Exports emails in the selected folder, and its sub-folders, to an mbox file, and generates Eudora index files.  There are two index files: one is named <mailbox>.toc, and the other is named descmap.pce.  The folder structure is not preserved.  Use this function to generate files that may be imported into Outlook Express.

The remaining menu selections are straight-forward.

  • File Open: Opens the Filing Cabinet, and loads the folder hierarchy into the left-side window.
  • File Close: Closes the current cabinet.
  • File Exit: Exits the application.
  • Edit Copy: Copies the selected text to the clipboard.
  • Tools About: Displays the version number and date of the application.

Startup Options

There is one optional parameter when starting the application.  You can supply the cabinet path and file name on the command line, and the main window will open and immediately load the cabinet file.

java -jar pfcview.jar [pfcfile]

You can also use the javaw command to start the application.  This command does not require a Command Window to run, which makes it convenient if you are setting up a Windows shortcut to start the application.  In the shortcut properties, enter the following settings:

Target:   javaw -jar pfcview.jar [pfcfile]
Start in: [directory path for pfcview.jar]

MailToMbox

The MailToMbox application performs a simple export of all mail messages in the Filing Cabinet to a single mbox file.  The folder structure of the cabinet is completely ignored, which makes the program useful if PFC Viewer is unable to read or interpret the internal pointers defining the file structure.  (This may happen if the cabinet file has not been compacted in a long time, or if the file is slightly corrupted.)

To run the MailToMbox application in Windows, open a Command Prompt (or MS-DOS Prompt) window, navigate to the directory where you saved the pfcview.jar file, and run the following command:

java -cp pfcview.jar MailToMbox [pfcfile] [mboxfile].mbx

The suggested file extension for the destination mbox file is .mbx, which is used by Eudora for Windows.  MailToMbox is strictly a console application, so no windows will appear.  The program will report its results in the command window when the export is finished.
